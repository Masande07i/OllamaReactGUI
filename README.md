## Description

```Ollama React GUI is a simple AI chatbot built with React and Ollama. It allows users to interact with locally running AI models through a clean and modern chat interface.The application communicates with the Ollama API to generate AI responses without relying on external AI cloud services.```

## Installation and set-up

Clone the repository:
git clone https://github.com/Masande07i/OllamaReactGUI.git

cd OllamaReactGUI



## Run project

npm install
# or
yarn install

npm run dev


## Tech Stack
1. React
2. Typescript
